# lf-sample-lfsdknet
Laserfiche SDK sample Visual Studio 2022 programs targeted at .NET Framework 4.8 and written in C# and VB.NET which demonstrate the use of various facilities provided by the RepositoryAccess and DocumentServices .NET libraries. C# programs can be found under the CSSamples solution, and the VB.NET sample programs can be found under VBSamples.
