OCREngineSample C# Sample Readme
================================

The OCREngineSample C# sample project for the Laserfiche SDK demonstrates 
using the RepositoryAccess and DocumentServices libraries to OCR a document
in a Laserfiche repository.  The sample shows signing in to a repository,
retrieving a document, and running an OCR proecess on the image pages in the
document, specifying the desired OCR accuracy and any special options.
